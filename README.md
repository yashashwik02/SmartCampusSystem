
🎓 Smart Campus Information System

Overview

The Smart Campus Information System is a Python-based application designed to simplify and automate essential campus management activities. The system integrates multiple modules into a single platform, providing an efficient way to manage student information, course enrollment, fee processing, records management, and performance analytics.

Features

- 👨‍🎓 Student Registration and Management
- 📚 Course Enrollment System
- 💰 Automated Fee Calculation
- 📊 Performance Analytics
- 🗂️ Student Records Management
- 📁 File Management Utilities
- 🔍 Directory Scanning and Search Operations
- 🖥️ User-Friendly Graphical Interface

Technologies Used

- Python
- Tkinter (GUI)
- JSON Data Storage
- Object-Oriented Programming

Project Structure

- "main_application.py" – Main GUI Application
- "student_registration.py" – Student Registration Module
- "course_enrollment.py" – Course Enrollment Module
- "fee_calculation.py" – Fee Calculation Module
- "student_records.py" – Student Records Management
- "performance_analytics.py" – Performance Analytics
- "file_manager.py" – File Handling Utilities
- "directory_scanner.py" – Directory Management
- "search_sort.py" – Search and Sorting Operations

Workflow

1. Register Student
2. Enroll in Courses
3. Calculate Fees
4. Store Student Records
5. Analyze Performance
6. Manage Campus Data Efficiently
